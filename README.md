## 🚀 Featured Projects

### 🌍 [GeoSignal](https://github.com/krishnasurya9/GeoSignal)
**Geopolitical Intelligence & Historical Event Replay**

A proposed architecture for monitoring geopolitical developments and tracing their potential impact on financial markets and economic sectors.

- Integrates GDELT event data and GKG news metadata.
- Uses historical replay to evaluate the feasibility of the proposed monitoring workflow.
- Incorporates NSE/Nifty market data for historical event-to-market analysis.
- Initial case study focuses on Red Sea and Houthi-related developments.

`Python` `GDELT` `NLP` `Time-Series Analysis` `Data Engineering`

### 🕸️ [Disrupting Dark Networks](https://github.com/krishnasurya9/disrupting-dark-networks)
**Graph Vulnerability Analysis & Intelligent Network Dismantling**

A graph-based framework for studying the resilience and vulnerability of covert networks using classical network science and reinforcement learning.

- Analyzes real-world and synthetic networks, including the Krebs 9/11 network, Morselli Caviar syndicate, Barabási–Albert graphs, and the Elliptic Bitcoin network.
- Implements centrality measures, Collective Influence ranking, and network resilience metrics.
- Develops a sequential network dismantling engine.
- Integrates a Gym environment with a GNN-based Deep Q-Network.
- Includes an interactive HTML dashboard and a 25-check testing pipeline.

`Python` `NetworkX` `PyTorch` `Gym` `GNN` `DQN`

### 🔍 [Metadata-Driven Intelligent News Article Retrieval System](https://github.com/krishnasurya9/Metadata-Driven-Intelligent-News-Article-Retrieval-System)
**Hybrid Search & Retrieval-Augmented Generation**

An intelligent news retrieval pipeline combining traditional information retrieval techniques with semantic search and LLM-based synthesis.

- Implements hybrid lexical and semantic retrieval.
- Uses FAISS for efficient vector similarity search.
- Supports metadata-based filtering to refine search results.
- Integrates RAG to generate contextual reports from multiple retrieved sources.

`Python` `FAISS` `RAG` `Hugging Face` `Information Retrieval`

### 🤖 Personality-Driven Recommendation Engine
**Personality-Aware Recommendation System**

A recommendation engine that uses personality-related signals extracted from user text to generate personalized recommendations.

- Maps textual input to Big Five and MBTI personality dimensions.
- Uses a BERT-LSTM-based personality prediction approach.
- Provides recommendations across books, music, and games.
- Exposes the recommendation pipeline through a FastAPI backend.

`Python` `PyTorch` `BERT` `FastAPI` `Recommendation Systems`
